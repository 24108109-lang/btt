BÀI TẬP RESPONSIVE DESIGN - TANG THI PHUONG THAO

Các tệp:
- index.html: nội dung trang, 6 hình ảnh có alt và nội dung đoạn văn tự viết.
- style.css: bố cục mobile-first và 4 media queries theo yêu cầu.

Cách sử dụng:
1. Giải nén thư mục.
2. Mở index.html bằng trình duyệt để xem trang.
3. Nếu muốn đưa lên GitHub Pages, tải cả index.html và style.css lên cùng một thư mục trong repository.
4. Kiểm tra HTML tại https://validator.w3.org/nu/ và kiểm tra khả năng tiếp cận tại https://wave.webaim.org/ .
5. Các hình ảnh đang dùng URL ảnh Unsplash; cần kết nối Internet để hiển thị.
